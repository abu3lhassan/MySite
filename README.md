# Ali Premium Portfolio

Static premium portfolio website ready for GitHub Pages.

## Files
- `index.html` — public website
- `styles.css` — premium responsive design
- `script.js` — rendering, language toggle, animations, hidden editor
- `profile-data.js` — the only file you normally edit to update content
- `CNAME` — custom domain file

## Deploy on GitHub Pages
1. Create a new public repository, for example `ali-portfolio`.
2. Upload all files from this folder to the repository root.
3. Go to repository Settings → Pages.
4. Source: Deploy from branch.
5. Branch: `main`, folder: `/root`.
6. Add your custom domain in Pages settings.
7. In your DNS provider, point the domain to GitHub Pages.

## Update content
Edit `profile-data.js`, then commit the change.

## Hidden local editor
Open the hidden editor from this private route:
`https://yourdomain.com/abu3lhassanAdminZ/`

Alternative access also works with:
`https://yourdomain.com/#abu3lhassanAdminZ`

This lets you preview edits locally in the browser and download a new `profile-data.js` file. Visitors will not see the editor.


## Profile photo
Add your photo as `assets/profile.jpg`. Use a square image, recommended 1000x1000 px or 1200x1200 px, JPG/WebP, ideally under 500 KB. Keep your face centered with safe space around the edges because the design crops it as a circle.
