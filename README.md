# Ali Alhanabi — Public Portfolio Review

Static HTML/CSS/JavaScript portfolio intended for Cloudflare Pages.

## Deployment safety

- Review this repository for sensitive information before making it public.
- Create a Cloudflare Pages preview deployment from a separate branch.
- Verify both languages and mobile/desktop layouts before production release.
- No private editor or server-side CMS is included.
- Update site copy in `site-pages.js`, `profile-data.js`, and page HTML.
- Public corporate case studies are intentionally generalized; obtain employer approval for any specific internal project names or metrics.

## Local preview

Run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`.
